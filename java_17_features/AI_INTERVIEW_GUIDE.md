# AI Interview Guide

## What is AI?

Artificial Intelligence (AI) is the field of computer science focused on building systems that can perform tasks that normally require human intelligence, such as learning, reasoning, problem solving, understanding language, and recognizing patterns.

---

## Types of AI

### 1. Narrow AI

Also called weak AI, this type is designed for a specific task.

Examples:
- face recognition
- voice assistants
- spam filtering
- recommendation systems

### 2. General AI

This is a hypothetical form of AI that can perform any intellectual task a human can do.

It is still mostly a research goal.

---

## Subfields of AI

### Machine Learning (ML)

Machine Learning is a part of AI where systems learn from data instead of being explicitly programmed for every rule.

Example:
- predicting product demand
- fraud detection
- email classification

### Deep Learning

Deep Learning is a subset of machine learning that uses artificial neural networks with many layers.

Examples:
- image recognition
- speech recognition
- language models

### Natural Language Processing (NLP)

NLP helps machines understand and generate human language.

Examples:
- chatbots
- translation tools
- sentiment analysis

### Computer Vision

Computer Vision helps machines understand images and videos.

Examples:
- facial recognition
- object detection
- medical image analysis

### Robotics

Robotics combines AI with hardware to build systems that can interact with the physical world.

---

## Machine Learning Basics

### Supervised Learning

The model learns from labeled data.

Examples:
- email spam detection
- house price prediction

### Unsupervised Learning

The model learns from unlabeled data and finds hidden patterns.

Examples:
- customer segmentation
- anomaly detection

### Reinforcement Learning

The model learns by trial and error using rewards and penalties.

Examples:
- game AI
- robotics control

## AI Interview Questions and Answers

### 1. What is AI?

AI is the field of building software systems that can perform tasks that normally require human intelligence such as reasoning, prediction, and language understanding.

### 2. What is Machine Learning?

Machine Learning is a type of AI where models learn patterns from data to make predictions or decisions.

### 3. What is the difference between AI and ML?

AI is the broader field, while Machine Learning is a subfield of AI focused on learning from data.

### 4. What is Deep Learning?

Deep Learning uses neural networks with multiple layers to model complex patterns in data.

### 5. What is NLP?

NLP is the branch of AI that helps computers understand and generate human language.

### 6. What is a Neural Network?

A neural network is a computational model inspired by the human brain. It consists of layers of nodes that process data.

### 7. What is overfitting?

Overfitting happens when a model performs very well on training data but poorly on new data because it learned noise instead of real patterns.

### 8. What is underfitting?

Underfitting happens when a model is too simple and cannot learn the underlying pattern in the data.

### 9. What is model accuracy?

Accuracy measures how often the model makes correct predictions.

### 10. What is the difference between classification and regression?

- Classification predicts a category
- Regression predicts a continuous value

Example:
- classification: spam or not spam
- regression: house price prediction
